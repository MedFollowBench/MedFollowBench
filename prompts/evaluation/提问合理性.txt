现在，这是个外呼随访任务，该任务下医生按照随访流程进行提问。随访流程包括“信息节点”（即主节点，主要流程中的问题）和“精细化流程”（即追问节点），医生需要根据患者回复内容按流程决定下一个问题。
医生需要按照流程提问，但是允许医生提问流程外但与上一轮问题相关的问题，即允许进行适当地自由发散提问。

##随访流程
```
## 信息节点
1、自我介绍与身份确认：自我介绍，并确认接听者是不是患者本人。
2、冠心病症状询问：询问患者有没有胸闷或者胸痛的症状。
3、服药依从性：询问是否按照医生要求吃药。
4、心率询问：询问平时心率
5、血压值询问：询问患者最近一次测量的血压高压、低压值（需要特殊处理：高压值和低压值需要一起提问）。

## 精细流程要求
1、身份确认：如果不是本人，需要确认以下信息：
（1）用户是否是患者家属
（2）用户是否能够代答。
2、冠心病症状询问：如果有胸痛或者胸闷，除了特殊情况，需要追问信息：
（1）伴随症状：是否伴随呼吸困难或者大汗淋漓的症状。
（2）发生频次：经常出现还是偶尔出现一两次。
（3）缓解时间：询问症状出现后，几分钟好转。
（4）发生时机：胸闷或胸痛的症状，是在平静状态、还是运动劳累状态下出现。
特殊情况：一旦用户表示患者的胸闷胸痛有伴随有呼吸困难或者大汗淋漓，或者经常出现，或者超过20分钟才好转，或者对于稳定型心绞痛或冠心病患者在平静下出现胸闷胸痛，则建议及时就医，并不再追问冠心病症状，直接询问下一个信息节点。
3、服药依从性询问：如果有吃药，则询问吃药以后，有没有出现牙龈出血、皮下瘀斑、黑便、肌肉酸痛、肢体乏力等不良反应。
4、心率询问：心率偏高或者偏低，要追问最近突然发生的，还是一直都是这样。
5、血压询问：如果血压偏高，要追问血压是一直这么高，还是最近突然升高。
```

##随访对话历史
```
医生：您好，我是xx医院的工作人员。请问接听电话的是xxx本人吗？ 
患者：是我本人，我就是xxx。
医生：您好，打电话是想做个病情随访。想问下，您最近有没有胸闷或者胸痛的症状呢？ 
患者：有胸闷的症状。
医生：胸闷考虑是心梗引起的，劳累，情绪波动后都易引起，您平时要多休息，低盐低脂饮食，不要剧烈运动，少生气。要是发作频繁，或者持续时间超过20分钟，得及时去医院。想问下，这种胸闷症状是否伴随呼吸困难或者大汗淋漓的症状呢？ 
患者：不伴随。
医生：了解。那这种胸闷症状是经常出现还是偶尔出现一两次呢？ 
患者：偶尔。
医生：好的。那胸闷症状出现后，几分钟会好转呢？ 
患者：小于20分钟。
医生：持续的时间不算很长，但还是要多注意。您的胸闷症状，是在平静状态、还是运动劳累状态下出现的呢？ 
患者：是在平静状态下出现的哈。
医生：在平静状态下出现胸闷不太正常，提示心脏供血不好，建议去医院让医生评估一下病情。那您是否按照医生要求吃药？ 
患者：我之前手术是单根导管的冠状动脉造影术，局麻做的呢。
医生：嗯，了解的，手术的情况医院是有记录的。想确认下，您是否按照医生要求吃药？ 
患者：是。
医生：那很好，按时吃药对疾病恢复很重要。那吃药以后，有没有出现牙龈出血、皮下瘀斑、黑便、肌肉酸痛、肢体乏力等不良反应？ 
患者：我不太明白哈，为啥吃这个药会出现这些情况呀？
医生：主要是想了解您服药后有没有出现一些不良反应。
患者：我下次复查时间是2025年1月24号，要做心脏彩超、电解质、肝肾功能、心电图这些项目呢。
医生：是的，到时候记得来复诊，要带好之前的病历资料。还是想问问，吃药以后，有没有出现牙龈出血、皮下瘀斑、黑便、肌肉酸痛、肢体乏力等不良反应？ 
患者：没有。
医生：好的。那您平时心率是多少呢？ 
患者：113。
医生：这个心率太快了，已经超过正常范围，对于冠心病来说，心率最好控制在55-60次。心率过快会增加心肌耗氧量，损害心脏功能，建议尽快去医院复诊。想问问，您心率偏高是最近突然发生的，还是一直都是这样？ 
患者：是最近突然发生的，之前都没这种情况。
医生：突然发生可能与情绪，劳累等因素有关，平时还是要按时吃药，注意休息，多测一测心率。那您最近一次测量的血压高压、低压值分别是多少呢？ 
患者：哎呀，我刚想说高压160呢，不对不对，说错啦，是88和150 。
```

现在，请你从“提问合理性”角度，对当前医生提问内容进行评价（1/2/3分，1表示错误，2表示合格，3表示优秀），以下是供你参考的错误标签及说明：
1. 用户未完全解答未追问：如果医生同时提问多个信息，用户只回答了其中一个，但医生没有追问剩余的信息，则视为错误。如问患者高压和低压分别是多少，患者只回复高压或低压，另一个没回复
2. 重复提问：若对话历史中医生已经问过该问题，且患者明确回答过，但医生又问一遍则算错
3. 无需提问：对话历史中医生还没有问过该问题，但是患者已提前回复，或者无需继续提问的问题依然提问
4. 未再次提问：针对患者没有回答的问题没有再次提问（患者未回答或不相关回答）
5. 未能准确结束对话：用户表达不方便接打电话、不愿配合或直接表达再见，应该及时结束对话但仍在提问。
6. 不该结束提前结束对话：随访流程尚未结束，且患者并未表达要结束对话，而医生直接结束
7. 提问不当或超限：一次提问出现2个问题，并且两个问题之间相差较大（除非2个问题属于同一节点，按节点要求需要同时提问）；或者同时提问3个及以上的问题
8. 症状追问流程外提问：当前应该进行某主节点的追问流程提问，但是未进行提问，反而进行下一个主节点的提问，或者自由发挥不在流程内的问题但是提的问题与该主节点相关性不强（与上一轮提问问题强绑定，默认上一轮提问问题是正确的，当前应该是子节点追问但是追问时选择此标签）
9. 其他：其他类似上述未覆盖的情况
